# แบบเก็บข้อมูลร้าน

ใช้เก็บข้อมูล 1 ร้าน ก่อนติดตั้ง AICP คัดลอกไฟล์นี้ 1 ชุดต่อ 1 ร้าน

**ห้ามเก็บไฟล์ที่กรอกแล้วใน repo นี้** เพราะ repo ยังเป็น public และห้ามใส่รหัสผ่าน คีย์ หรือ token ลงในไฟล์ ถ้าต้องรับค่าเหล่านี้ให้ใช้ช่องทางที่ปลอดภัยแยกต่างหาก

| ป้าย | ใช้กับ |
|---|---|
| ทุกแพ็ก | เก็บทุกร้าน |
| เว็บ | ร้านที่ซื้อเว็บแชท |
| LINE | ร้านที่ซื้อระบบตอบแชต LINE |

| | |
|---|---|
| ชื่อร้าน | |
| วันที่เก็บข้อมูล | |
| ผู้เก็บข้อมูล | |
| แพ็กที่สนใจ (ร่าง ยังไม่ล็อก) | เว็บ + คลังความรู้ / LINE + คลังความรู้ / ครบ 3 ส่วน |
| รูปแบบที่สนใจ (ร่าง ยังไม่ล็อก) | พร้อมเซ็ตอัป / ไม่รวมเซ็ตอัป |

แพ็กและรูปแบบขายในตารางนี้ยังเป็นร่าง ใช้ถามความสนใจเท่านั้น ยังไม่ใช่ข้อเสนอขาย

## 3. เอกสารความรู้ (ทุกแพ็ก)

ระบบรับ FAQ, PDF และ CSV ไฟล์ละไม่เกิน 5 MB

- **customer:** บอทใช้ตอบลูกค้าได้
- **internal:** พนักงานเท่านั้น ห้ามตอบลูกค้า

เอกสารแต่ละฉบับต้องมีคนรับผิดชอบ และต้องรู้ว่าจะล้าสมัยเมื่อไร ถ้าไม่แน่ใจให้เลือก internal ก่อน

| เอกสาร | มีไหม | ไฟล์ | ใช้กับ (customer/internal) | ผู้รับผิดชอบ | อัปเดตล่าสุด | ต้องทบทวนเมื่อ |
|---|---|---|---|---|---|---|
| คำถามที่พบบ่อยพร้อมคำตอบ | | | | | | |
| รายการสินค้าหรือบริการ พร้อมราคา | | | | | | |
| โปรโมชันปัจจุบันและวันหมดเขต | | | | | | |
| การสั่งซื้อและการชำระเงิน | | | | | | |
| การจัดส่ง ค่าส่ง และระยะเวลา | | | | | | |
| การคืนสินค้า คืนเงิน และเงื่อนไข | | | | | | |
| การรับประกันและบริการหลังการขาย | | | | | | |
| การจองหรือการนัดหมาย | | | | | | |
| คู่มือใช้สินค้า | | | | | | |
| ระเบียบหรือคู่มือพนักงาน | | | | | | |

**ก่อนส่งเอกสาร ตรวจ 3 ข้อ:**
- ลบข้อมูลส่วนตัวของลูกค้าออกจากไฟล์ทั้งหมด
- เอกสารแต่ละฉบับไม่ขัดกันเอง เช่น ราคาหรือเงื่อนไขคนละแบบ
- PDF ต้องเลือกข้อความได้ ไฟล์ที่เป็นภาพสแกนต้องทดสอบก่อนว่าระบบอ่านได้

## 4. คำถามจริงจากลูกค้า (ทุกแพ็ก)

เก็บ 30–50 คำถาม จากแชตเก่าโดยคัดลอกเฉพาะคำถาม ไม่เอาชื่อหรือข้อมูลลูกค้ามาด้วย และควรเก็บคำพูดจริง ไม่ต้องเรียบเรียงใหม่

ชุดนี้ใช้ทดสอบว่าบอทตอบถูกไหม ไม่ได้ใช้ฝังคำตอบลงในระบบ

| คำถามจริง | คำตอบที่ถูกต้อง | มาจากเอกสารไหน | ควรทำอย่างไร (ตอบ/ส่งต่อคน) |
|---|---|---|---|
| | | | |

ควรมีคำถามที่บอทไม่ควรตอบปนอยู่ด้วยอย่างน้อย 10 ข้อ เช่น เรื่องที่ไม่มีในเอกสาร

## 12. เช็กลิสต์ก่อนเริ่มติดตั้ง

**ทุกแพ็ก**
- [ ] มีผู้อนุมัติเอกสารแล้ว
- [ ] ได้ข้อมูลร้าน และเวลาทำการ
- [ ] มีเอกสาร customer ที่อนุมัติแล้วอย่างน้อย 1 ฉบับ
- [ ] มีคำถามจริงอย่างน้อย 30 ข้อ พร้อมคำตอบที่ถูกต้อง
- [ ] มีคนรับเรื่องที่บอทส่งต่อ
- [ ] ร้านรับทราบเรื่องที่บอทไม่ทำเอง
- [ ] เจ้าของบัญชี Supabase และโฮสต์พร้อมแล้ว
- [ ] ลบข้อมูลส่วนตัวของลูกค้าออกจากเอกสารแล้ว

**เว็บ**
- [ ] ตกลงที่วางแชทแล้ว (ลิงก์ของตัวเอง หรือบนเว็บร้าน) ถ้าวางบนเว็บร้านต้องได้โดเมนครบ

**LINE**
- [ ] มีผู้มีสิทธิ์ Admin ใน LINE Developers
- [ ] ตกลงเรื่อง webhook เดิมแล้ว
- [ ] ปิด Greeting Message และ auto-reply แล้ว

## หมายเหตุสำหรับทีม WSTERA (ไม่ต้องส่งให้ร้าน)

แพ็กและรูปแบบขายยังเป็น PROVISIONAL ตาม D-20261105-02 ที่วางแชทเริ่มจากหน้าแชทมีลิงก์ของตัวเอง

ข้อมูลบางส่วนในแบบนี้ระบบยังไม่มีที่เก็บ ณ `main` `7350fa2`:

| ข้อมูล | สถานะ |
|---|---|
| เอกสารความรู้ และ customer/internal | รองรับแล้ว ระดับ `BUILD_PASS` |
| ผู้ใช้และสิทธิ์ owner/staff | รองรับแล้ว ระดับ `BUILD_PASS` |
| น้ำเสียง, เวลาทำการ, เรื่องที่ต้องส่งต่อเสมอ | ยังไม่มี (Business Configuration อยู่ในร่าง Core Contract) |
| โดเมนต่อร้าน (`allowedOrigins`) | ยังไม่มีในสคีมา ต้องทำในงานโฮสต์จริง |
| การส่งต่อคนแบบถาวร | ยังไม่มี (HANDOFF-002) |
| ระยะเก็บประวัติแชท | ยังไม่มี |

ค่าของแต่ละร้านต้องเก็บเป็นข้อมูลหรือการตั้งค่าของ workspace ห้ามฝังลงโค้ด (D-20261105-01)
