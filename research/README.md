## Interpretation

- **Fact:** an explicit statement traceable to cited official docs or inspected code.
- **Vendor claim:** advertised product capability, not independently exercised.
- **Assumption/Proposal:** technical or commercial recommendation pending tests.
- **Blocker:** missing evidence that prevents production or commercial claims.

Do not use GitHub Star counts or marketing claims as performance benchmarks. Re-check current documentation before hardening deployment. Research does not replace measured tests with Thai shop data.
